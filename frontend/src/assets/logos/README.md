# Team logos

Official IPL franchise logos are trademarked, so none are bundled. Until you add them, every team
shows a clean fallback badge (initials on the franchise colour).

To use real logos, drop image files into this folder named after the **short code in lower case**:

    csk.png   mi.png   rcb.png   kkr.png   rr.png   srh.png   dc.png   pbks.png ...

Supported: `.svg`, `.png`, `.webp`, `.jpg`. Codes: CSK, MI, RCB, KKR, RR, SRH, DC, PBKS, GT, LSG,
DCH (Deccan Chargers), KTK (Kochi Tuskers Kerala), PWI (Pune Warriors India), RPS (Rising Pune Supergiant), GL (Gujarat Lions).

No code changes needed - files are picked up automatically at build/dev start.
